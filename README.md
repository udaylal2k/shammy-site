# Shaamy Lounge — website

Static site for Shaamy Lounge Unisex Salon, Davangere. Live at https://udaylal2k.github.io/shammy-site/

- `index.html` home · `menu.html` women's + men's menu · `story.html` founder story · `404.html`
- `css/site.css` all styles (brand colours are the variables at the top)
- `js/site.js` menu tabs, scroll reveal, WhatsApp booking builder
- `images/` photos (WebP variants for phones are generated from the originals) from the salon's original site · `menus/` the salon's own menu PDFs

Edit any file on github.com (pencil icon) and commit; GitHub Pages redeploys in about a minute.
Service lists are transcribed from the salon's menu PDFs, which carry no prices.
